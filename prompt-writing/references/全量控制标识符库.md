# 全量控制标识符库

本文件是控制功能标识符的唯一登记库。后续所有已确认的控制标识符都必须登记在此处；未确认的候选标识符不得写入。

## 登记要求

- 每条记录至少包含：功能名称、功能标识符、功能描述。
- 功能描述应说明功能的使用场景、控制对象和控制目的，帮助后续判断是否可以复用已有标识符。
- 只有功能语义、控制对象、控制目的和使用场景均一致时，才允许复用已有标识符。
- 功能名称相似但使用场景或控制目的不同，应登记为不同标识符。
- 同一功能存在不同名称时，只保留一条记录，并在功能描述中补充其他名称作为同义表达。
- 无法根据现有描述判断是否为同一功能时，先向需求提出人确认控制对象、使用场景、控制目的和执行效果，再决定复用或新增。
- 标识符确认后及时补充记录；候选状态、待确认词汇和临时命名不登记。

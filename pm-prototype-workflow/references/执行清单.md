# 原型绘制执行清单

结论先行：本清单是每次绘制原型的最小必做集，供任意客户端在加载主 Skill 后逐步核对。它只做索引与门禁，不新增、不覆盖 `SKILL.md` 正文规则；两者冲突时以 `SKILL.md` 为准。

## 1. 八步门禁

| # | 必做 | 通过判定 | 依据 |
| --- | --- | --- | --- |
| 1 | 完整读取 `SKILL.md` 全文（不只读摘要、不按标题挑章节），并按「强约束资源入口」依次读取所列资源 | 能说明本次适用的档案、锁定项与禁止项 | 强约束资源入口 |
| 2 | 明确本次页面、状态、屏号、非目标范围与已确认 PRD；有真实系统来源时先出元素对照清单 | 范围与业务语义均有来源，缺项记为「待确认」 | 默认流程 / 真实系统还原规范 |
| 3 | 声明且只选一个风格档案 `project` 或 `personal`，记录事实源，写入根节点 `data-style-profile` | HTML 根节点有档案标记，交付记录有事实源 | 风格档案选择 |
| 4 | 在聊天框输出低保真线框图并等待用户明确确认 | 收到明确确认后才创建或更新 HTML | 静态原型流程 |
| 5 | 形成页面状态清单、流转清单、控件与图标清单 | 三张清单外的屏、箭头、控件、图标不进入正式 HTML | 质量基线与禁止自由发挥 |
| 6 | 从所选档案的锁定壳层或完整模板复制起稿，只替换已确认内容槽；零外链，图标取自 Skill 资产 | 无自造壳层、无 CDN、无字符或 emoji 图标 | 核心约定 / 图标库 |
| 7 | 运行自检脚本（命令见 `SKILL.md`「宿主无关执行约定」） | 退出码 0，`--json` 无问题项 | 强约束资源入口 |
| 8 | 浏览器打开、关键操作冒烟、截图回读、人工视觉检查；四类结果分别报告并等待用户确认 | 四类检查均有结论；脚本通过不代替视觉检查与用户确认 | 原型交付门禁 |

## 2. 未通过时

- 任一机器检查失败：修正后重跑第 7 步，不以「看起来没问题」放行。
- 环境受限（无浏览器或预览能力）：在交付说明写「未执行」及原因，不记为通过，仍完成第 8 步中其他可执行的检查。
- 风格档案、业务状态或流转缺来源：先向用户澄清，不自行补造，也不静默回退到默认档案。

## 3. 交付说明固定四项

| 项 | 要写什么 |
| --- | --- |
| 机器检查 | 自检命令、退出码、问题清单 |
| 浏览器检查 | 打开方式、加载错误数、关键操作结果 |
| 视觉回读 | 截图方式，壳层、图标、文案、溢出的核对结论 |
| PRD 追踪 | 屏号清单、状态覆盖、流转依据、差异与有意省略 |

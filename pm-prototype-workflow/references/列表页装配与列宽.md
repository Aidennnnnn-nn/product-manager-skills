# 列表页装配与列宽

本参考约束列表与管理页的区块装配顺序、表格列宽、对齐、横向滚动和操作列吸附。它不规定项目品牌色值、筛选字段内容和业务状态定义。用户当前要求和项目已确认设计系统优先。

分页条本身见 [列表与分页控件](列表与分页控件.md)，本参考不重复。

## 使用边界

- 适用于静态多屏评审稿和可交互原型的列表与管理页。详情页、表单页的字段布局不适用。
- 列宽默认按本参考的四档与总宽策略推算；项目已有表格组件或列宽规范时复用项目值，同时保留本参考的对齐、吸附和压缩优先级。
- 列宽不足时先按优先级压缩列，不靠缩小字号或压缩行高换取空间。

## 1. 页面区块装配

列表页自上而下固定为五个区块，顺序不可调换：

| 区块 | 内容 | 装配条件 |
| --- | --- | --- |
| 页面标题 | 标题 + 页面级主操作 | 必装 |
| 筛选区 | 字段标签在上、控件在下；末端「查询」→「重置」 | PRD 无筛选条件时不装配 |
| 工具栏 | 新增、导出、批量操作、列设置 | 无此类动作时整块省略，不留空位、不占高度 |
| 表格 | 表头、数据行、行操作 | 必装 |
| 分页 | 见 [列表与分页控件](列表与分页控件.md) | 必装 |

| 区块间 | 间距 |
| --- | --- |
| 标题 ↔ 筛选区 | `24px` |
| 筛选区 ↔ 工具栏 | `16px` |
| 工具栏 ↔ 表格 | `16px` |
| 表格 ↔ 分页 | `0`（分页自带 `border-top` 与 `8px 16px` 内边距） |

筛选区的字段排列与控件形态按 [控件与空间规范](控件与空间规范.md)；本参考只管它与表格之间的垂直节奏。

## 2. 表格结构

| 项 | 规则 |
| --- | --- |
| 表头高度 | `40px`；底色 `#f7f7f8`；文字 `12px`、`500` 字重、次级文字色 |
| 单行数据高度 | `50px` |
| 双行堆叠高度 | `64px`（主值 + 次要说明上下两行） |
| 单元格内边距 | `7px 10px` |
| 分隔线 | 只用行的下边框 `1px`，不画竖线 |
| 斑马纹 | 不使用 |
| 行 Hover | 底色 `#fafafa` |
| 表头吸顶 | `position: sticky; top: 0; z-index: 5` |
| 行操作 | 默认直接展开为文字按钮，不收进「更多操作」；仅 PRD 要求时用菜单 |

表头与数据行必须共用同一个滚动容器，保证横向滚动时两者同步位移。分页条放在滚动容器**之外**，不随表格横向滚动。

## 3. 列宽四档

| 档位 | 宽度 | 适用列 |
| --- | --- | --- |
| XS | `48–64px` | 序号、勾选、单图标 |
| S | `80–110px` | 状态、服务器、组织代码、短标签 |
| M | `120–160px` | 用户名、昵称、手机号、创建人、时间 |
| L | `170–220px` | 邮箱、地址、长文本 |

- 同类型的列在同一页面内使用同一档位，不逐列微调。
- 数值列按最大值的位数估宽，不按表头文字估宽。
- 状态标签列按最长状态文案 + 标签左右内边距 + 单元格内边距估算，不留过宽空白。

**操作列单独计算**，不套四档：

| 操作数量 | 宽度 | 计算 |
| --- | --- | --- |
| 1 个 | `96px` | 1 × 64 + 32 |
| 2 个 | `160px` | 2 × 64 + 32 |
| 3 个 | `224px` | 3 × 64 + 32 |
| 4 个 | `288px` | 4 × 64 + 32 |

操作列按操作数量定宽，不让内容撑开。行与行之间操作数量不同时（例如部分行多一个「恢复」），仍按最大操作数定宽，保证列不抖动。

## 4. 总宽策略

先算列宽合计，再按结果二选一：

| 条件 | 做法 |
| --- | --- |
| 列宽合计 ≤ 容器宽度 | `table { width: 100%; table-layout: fixed }`；多余空间只分给 L 与 M 档的文本列，XS、S 档和操作列保持固定 |
| 列宽合计 > 容器宽度 | 各列按固定宽度渲染，`.table-wrap { overflow-x: auto }`，操作列 `position: sticky; right: 0` 吸附右侧 |

- 判断依据是渲染后的实测值：`table.scrollWidth` 与 `.table-wrap.clientWidth` 的差值大于 0 即需要横向滚动，不能靠列宽相加估算，浏览器会按最小内容宽度重新分配。
- 允许横向滚动的表格，滚动条必须出现在表格容器内，不出现在页面上。
- 不允许「表格被裁切但没有滚动条」的中间态：要么放得下，要么可滚动。
- 不为了不出滚动条而缩小字号或压到文字截断。

**伸缩列标注**：`table-layout: fixed` 下若所有列都写死 px，表格撑满容器时会把每一列等比例拉宽，序号列和状态列也会跟着变胖。正确做法是只给固定列写 px：

| 列 | 写法 | 效果 |
| --- | --- | --- |
| XS、S 档与操作列 | 固定 `px` | 不参与伸缩，宽度恒定 |
| M、L 档的文本列 | 百分比 `%` | 按比例分配，随容器变化 |
| 唯一的伸缩列 | 不写宽度 | 自动吸收全部剩余空间 |

一列伸缩时留空即可；多列伸缩时按内容比例写百分比，比例之和不超过 `100%` 减去固定列占比。

**`min-width` 必须写 `max-content`，不能写 `100%`**。这是本参考里最容易写错的一处：

| 写法 | 容器放不下时 |
| --- | --- |
| `width: 100%; min-width: 100%` | 表格被压到容器宽度，所有列等比缩窄，**不产生横向滚动条**，文字被截断 |
| `width: auto; min-width: 100%` | 同上，列被压扁 |
| `width: 100%; min-width: max-content` | 表格宽度保持列宽合计，按需横向滚动，列宽不变形 |

实测：容器 `1200px`、12 列合计 `1514px`，第三种写法下表格 `1514px`、溢出 `314px`、各列宽度与 `colgroup` 完全一致；前两种写法表格被压到 `1200px`、无滚动条、列宽被压缩到原值的约 80%。

## 5. 压缩优先级

列宽合计超出容器时，按以下顺序处理，不跳步：

1. **不动**：操作列、关键识别列（用户名、名称、标题）、状态。
2. **先压**：创建人 → 创建时间 → 组织代码，各降到 S 档下限。
3. **再压**：所属组织 → 昵称。
4. **合并**：把弱关联的两列合成双行单元格（如创建人 + 创建时间上下两行），行高升到 `64px`。
5. **移出**：仍放不下时，把次要列移入详情页，列表只保留识别、状态和操作所需字段。

压缩后必须重新实测一次，确认无横向滚动且没有列被压到文字截断。

## 6. 对齐

| 内容类型 | 对齐 |
| --- | --- |
| 文本（名称、邮箱、组织、时间） | 左对齐 |
| 数值、金额、百分比、计数 | 右对齐 |
| 状态标签 | 左对齐，不居中 |
| 行操作 | 右对齐 |
| 序号 | 左对齐（列宽窄时可居中） |

表头对齐**跟随**该列内容的对齐方式，不统一居中。数值列表头右对齐后，表头与数据的小数点位置才对得上。

## 7. 操作列吸附

横向滚动时必须保证操作始终可达，操作列固定在容器右侧。以下只列吸附必需项，表格宽度与列布局以 10.2 的完整样式为准，不要单独套用本段。

需要横向滚动的表格给容器加 `table-wrap--scroll` 修饰类；放得下、不滚动的表格不加，避免多出无意义的投影：

```css
.table-wrap { width: 100%; overflow: auto; }
/* 吸附要求 separate；宽度与 table-layout 见 10.2 */
table { border-collapse: separate; border-spacing: 0; }
thead { position: sticky; top: 0; z-index: 5; }

.table-wrap--scroll thead th:last-child,
.table-wrap--scroll tbody td:last-child {
  position: sticky;
  right: 0;
  background: var(--surface);
  box-shadow: -8px 0 8px -8px rgba(9, 14, 29, .12);
}
.table-wrap--scroll thead th:last-child {
  background: #f7f7f8;
  z-index: 6;
}
```

四条必须同时满足：

- **必须有背景色**。吸附列不给背景时，横向滚动后下层内容会从列下面透出来。数据行用表面色，表头用表头底色。
- **表头吸附列的 `z-index` 高于普通表头**（`6` 对 `5`），否则交叉滚动时会被普通表头盖住。
- **用 `border-collapse: separate`，不用 `collapse`**。`collapse` 模式下边框属于表格而非单元格，吸附单元格的下边框会留在原位，滚动时出现断线。
- **左侧留一道投影**（`-8px` 偏移的 `box-shadow`），提示该列是固定的，不是内容边界。

未启用横向滚动的表格不加吸附，避免多余的投影和层级开销。

## 8. 长文本与溢出

- 单元格单行省略：`overflow: hidden; text-overflow: ellipsis; white-space: nowrap`。
- 被省略的内容提供 `title` 全量提示，或行内可展开；不靠 Tooltip 承载必读信息。
- 不通过换行撑高行高处理长文本；确需多行的字段（地址、备注）单独用双行堆叠规格。
- 状态标签列限制标签最大宽度，超出用省略号，标签不换行。

## 9. 四种状态

| 状态 | 表格区 | 分页条 |
| --- | --- | --- |
| 空（无数据） | 跨全部列居中，说明当前没有数据 + 「新建」入口 | 1 页，前后禁用 |
| 无结果（筛选后为空） | 跨全部列居中，说明没有匹配结果 + 「清空筛选」入口 | 1 页，前后禁用 |
| 加载 | 骨架行占位，保留表头 | 保留，整体禁用 |
| 错误 | 跨全部列居中，说明原因 + 「重试」入口 | 保留，整体禁用 |

- 空态与无结果文案不混用：前者引导创建，后者引导放宽条件。
- 加载态不伪装成空态，表头在加载期间仍然显示。
- 四种状态都占住表格区域原有高度，不把分页条顶上来导致布局跳动。

## 10. 代码

### 10.1 结构

```html
<div class="table-wrap">
  <table>
    <colgroup>
      <col style="width:52px">
      <col style="width:30%">
      <col>
      <col style="width:90px">
      <col style="width:224px">
    </colgroup>
    <thead>
      <tr>
        <th scope="col">序号</th>
        <th scope="col">用户名</th>
        <th scope="col">邮箱</th>
        <th scope="col">状态</th>
        <th scope="col" class="actions-cell">操作</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td>1</td>
        <td><span class="cell-ellipsis" title="zhangsan">zhangsan</span></td>
        <td><span class="cell-ellipsis" title="zhangsan@example.com">zhangsan@example.com</span></td>
        <td><span class="status-tag">正常</span></td>
        <td class="actions-cell">
          <div class="row-actions">
            <button class="row-action" type="button">编辑</button>
            <button class="row-action" type="button">删除</button>
          </div>
        </td>
      </tr>
    </tbody>
  </table>
</div>
```

`colgroup` 与表头列数必须一致；列宽写在 `col` 上，不逐列写 `th` 的 `width`，避免两处维护。示例中 `52px`、`90px`、`224px` 是固定列，用户名列取容器宽度的 `30%`，邮箱列留空吸收剩余空间。列宽合计超过容器、需要横向滚动时，给容器加 `table-wrap--scroll`，操作列才吸附右侧。

### 10.2 样式

```css
.table-wrap {
  width: 100%;
  overflow: auto;
}

table {
  width: 100%;
  /* 关键：max-content 而非 100%。写 100% 会在容器放不下时把列压扁且不出滚动条 */
  min-width: max-content;
  border-collapse: separate;
  border-spacing: 0;
  table-layout: fixed;
}

thead { position: sticky; top: 0; z-index: 5; }

th {
  height: 40px;
  padding: 0 10px;
  color: var(--ink-60);
  background: #f7f7f8;
  border-bottom: 1px solid var(--line);
  font-size: 12px;
  font-weight: 500;
  text-align: left;
  white-space: nowrap;
}

td {
  height: 50px;
  padding: 7px 10px;
  border-bottom: 1px solid var(--line);
  color: var(--ink);
  font-size: 12px;
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}

tbody tr:hover { background: #fafafa; }

.cell-ellipsis {
  display: block;
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}

th.num, td.num { text-align: right; }

.actions-cell { text-align: right; }
.row-actions { display: inline-flex; align-items: center; justify-content: flex-end; gap: 2px; }

/* 横向滚动时操作列吸附右侧；容器加 table-wrap--scroll 才启用，放得下的表格不加 */
.table-wrap--scroll thead th:last-child,
.table-wrap--scroll tbody td:last-child {
  position: sticky;
  right: 0;
  background: var(--surface);
  box-shadow: -8px 0 8px -8px rgba(9, 14, 29, .12);
}
.table-wrap--scroll thead th:last-child {
  background: #f7f7f8;
  z-index: 6;
}
```

变量映射：`--line` 描边色、`--ink` 主文字色、`--ink-60` 次级文字色、`--surface` 表面色。无项目规范时分别取 `#E3E8EF`、`#1F2733`、`#5B6472`、`#FFFFFF`。

### 10.3 列宽体检

改完列宽后实测一次，不靠相加估算：

```js
const wrap = document.querySelector('.table-wrap');
const table = wrap.querySelector('table');
const overflow = table.scrollWidth - wrap.clientWidth;
console.log({ tableWidth: table.scrollWidth, containerWidth: wrap.clientWidth, overflow });
```

`overflow > 0` 表示需要横向滚动。此时必须已在操作列启用吸附；`overflow <= 0` 时表格应撑满容器，不应出现滚动条。

## 11. 验收清单

- 五个区块顺序正确，工具栏无内容时整块省略，不留空白高度。
- 列宽来自四档，操作列按操作数计算，行与行之间列宽一致、无抖动。
- 列宽合计与容器宽度有明确结论：放得下则无横向滚动条且序号、状态、操作列宽度不变形；放不下则可滚动、列宽不被压缩、操作列恒可见。
- 横向滚动到任意位置，操作列右边界与容器右边界重合，按钮可点击、无遮挡。
- 表头与数据行横向同步位移；纵向滚动时表头吸顶在容器顶部。
- 吸附列有背景色，滚动时下层内容不透出；表头吸附列不被普通表头覆盖。
- 长文本单行省略并提供全量提示，没有撑破单元格或撑高行高。
- 数值列右对齐、文本左对齐、状态标签左对齐、操作列右对齐，表头跟随列内容。
- 空、无结果、加载、错误四态占住原表格高度，分页条位置不跳动；空态与无结果文案区分。
- 分页条在滚动容器之外，不随表格横向滚动。

# 列表与分页控件

本参考是 `pm-prototype-workflow` 的标准控件实体之一，用于列表与管理页的分页条。它给出可直接复用的结构、尺寸、页码序列算法与脚本，不规定项目品牌色值、表格列定义和筛选字段。用户当前要求和项目已确认设计系统优先。

## 使用边界

- 适用于静态多屏评审稿和可交互原型的列表与管理页；详情页、表单页、结果页不装配分页。
- 只约束分页条本身的结构、尺寸、状态和交互。表格列宽、筛选区排布、批量操作栏不在本参考范围。
- 项目已有分页组件时复用项目组件，同时保留本参考的页码序列算法、跳页边界和禁用口径。
- 数据不足一页时仍保留分页条：页码只有 `1`，上一页与下一页均禁用。不为单页数据隐藏分页条，避免列表区高度随数据量跳变。

## 1. 结构

分页条固定三段式，顺序不可调换：

| 段 | 内容 | 布局 |
| --- | --- | --- |
| 左 | 上一页按钮 → 页码序列 → 下一页按钮 | 按内容撑开，不压缩 |
| 中 | 弹性留白 | `flex: 1`，吸收多余宽度 |
| 右 | 每页条数选择 → 「跳至」→ 页码输入 → 「页」 | 固定宽度，禁止挤压折行 |

页码序列只渲染页码按钮与省略号。默认不渲染「共 N 条」「第 X / Y 页」等总量文案，总量口径见第 6 节。

## 2. 尺寸基线

| 元素 | 尺寸 | 说明 |
| --- | --- | --- |
| 分页条 | 高 `56px`；上下内边距 `8px`、左右 `16px`；上边框 `1px` | 用上边框分隔表格与分页，不加底色和阴影 |
| 页码按钮、上一页、下一页 | 最小 `32 × 32px`，圆角 `8px`，左右内边距 `8px` | 一位数与多位数页码按内容伸展，不跳位 |
| 页码序列容器 | 元素间距 `8px` | 与分页条整体间距一致 |
| 省略号 | 最小宽 `24px`，居中，字距 `1px` | 不可点击，不进入键盘 Tab 序列 |
| 每页条数选择 | 宽 `104px`、高 `32px` | 使用 Select 增强包装时，包装层同步锁定同一宽度 |
| 跳页输入 | 宽 `56px`、高 `32px`、圆角 `8px`，文字居中 | 加 `inputmode="numeric"`，只接受数字 |
| 「跳至」「页」文案 | `12px`，`white-space: nowrap` | 不随容器变窄折行，也不被下拉挤压成竖排 |

所有尺寸取项目空间 Token；项目无规范时用上表值，不临时改写某一处。

## 3. 状态

| 状态 | 表现 | 语义要求 |
| --- | --- | --- |
| 当前页 | 主色描边 + 主色文字 + `600` 字重 + 白底 | 同时加 `aria-current="page"`，不只靠颜色区分 |
| 上一页禁用 | `opacity: .35`、`cursor: not-allowed`、原生 `disabled` | 当前页为第 1 页时生效 |
| 下一页禁用 | 同上 | 当前页为末页时生效 |
| 页码 Hover | 边框转主色，文字与字重不变 | 不改尺寸、不加粗，避免布局跳动 |
| 跳页输入聚焦 | 边框转主色 | 不改变高度与圆角 |

分页条本身不进入加载态。数据刷新期间保留现有页码和总数，只禁用分页条上的全部可操作元素，刷新完成后解除。

## 4. 页码序列算法

设总页数为 `N`、当前页为 `c`：

| 条件 | 序列 |
| --- | --- |
| `N ≤ 7` | `1 2 3 … N` 全部展示 |
| `c ≤ 3` | `1 2 3 4 5 … N` |
| `c ≥ N - 2` | `1 … N-4 N-3 N-2 N-1 N` |
| 其他 | `1 … c-1 c c+1 … N` |

- 首末页恒常显示，任意位置都能一跳到底。
- 省略号最多出现两次，且不连续出现、不替代首末页。
- 序列长度恒为 7 个位置（含省略号），翻页时不产生宽度跳动。
- 总页数计算为 `max(1, ceil(总条数 / 每页条数))`，无数据时按 1 页处理，不出现 0 页。

## 5. 每页条数与跳页

- 每页条数默认 `10`，选项 `10 / 15 / 30 / 50 / 100`；选项文案写作「N 条/页」。
- 切换每页条数后回到第 1 页，不保留原页码。
- 筛选、搜索、切换数据视图后回到第 1 页。
- 数据量缩减导致当前页超出总页数时钳到末页；下限为 1，不出现第 0 页。
- 跳页在 `Enter` 与失焦两个时机生效，两处共用同一处理函数，避免两套逻辑不一致。
- 空值与非数字忽略：清空输入框，不翻页，不报错。
- 越界取最近边界页：小于 `1` 取第 1 页，大于总页数取末页。
- 跳转生效后清空输入框，包括目标页等于当前页的情况。

## 6. 总量展示口径

- 默认不展示「共 N 条」，总页数只由页码序列表达。这是个人标准的默认口径。
- 项目规范或 PRD 明确要求总量时再补，补时写在分页条右侧、与每页条数同一字号，不重复展示「第 X / Y 页」。
- 需要在表格上方展示总量时，把它放进工具栏或结果说明位置，不在分页条内重复。

## 7. 代码

以下三段可直接复制。样式变量按下表映射到项目变量，不新增第二套命名。

| 变量 | 含义 | 项目无规范时的参考值 |
| --- | --- | --- |
| `--line` | 描边色 | `#E3E8EF` |
| `--surface` | 表面色 | `#FFFFFF` |
| `--ink` | 主文字色 | `#1F2733` |
| `--ink-60` | 次级文字色 | `#5B6472` |
| `--ink-40` | 弱化文字色（省略号） | `#A0A8B4` |
| `--brand` | 主色 | 取项目主色，无规范时用当前原型主色 |

### 7.1 结构

```html
<div class="pagination">
  <button class="page-button" id="prevPage" type="button" aria-label="上一页">
    <i data-lucide="chevron-left"></i>
  </button>
  <div class="pager-numbers" id="pagerNumbers"></div>
  <button class="page-button" id="nextPage" type="button" aria-label="下一页">
    <i data-lucide="chevron-right"></i>
  </button>
  <div class="grow"></div>
  <select id="pageSize" class="control page-size" aria-label="每页条数">
    <option value="10">10 条/页</option>
    <option value="15">15 条/页</option>
    <option value="30">30 条/页</option>
    <option value="50">50 条/页</option>
    <option value="100">100 条/页</option>
  </select>
  <span>跳至</span>
  <input class="page-jump" id="jumpPage" type="text" inputmode="numeric" autocomplete="off" aria-label="跳至页码" />
  <span>页</span>
</div>
```

表格容器宽度足够（≥ `720px`）时用上面的平铺结构。容器更窄，或分页条要放进抽屉、侧栏、双栏对照时，把「跳至 / 输入框 / 页」包进 `.pager-jump-group`，配合 7.2 的窄视口规则整组下移，避免「跳至」与「页」被拆到两行或右侧被裁切：

```html
<div class="pager-jump-group">
  <span>跳至</span>
  <input class="page-jump" id="jumpPage" type="text" inputmode="numeric" autocomplete="off" aria-label="跳至页码" />
  <span>页</span>
</div>
```

图标按 [图标库](图标库.md) 取 `chevron-left` / `chevron-right`；渲染页码后调用项目的图标刷新函数一次。未接入图标库时不得用 `‹`、`›` 或其他字符替代，必须先接入 Skill 图标资产后再交付。

### 7.3 脚本

```js
const pagerState = { page: 1, size: 10, total: 0, render: () => {} };

function pagerTotalPages(total, size) {
  return Math.max(1, Math.ceil(total / size));
}

function pagerItems(totalPages, cur) {
  if (totalPages <= 7) {
    const list = [];
    for (let i = 1; i <= totalPages; i += 1) list.push(i);
    return list;
  }
  if (cur <= 3) return [1, 2, 3, 4, 5, '…', totalPages];
  if (cur >= totalPages - 2) return [1, '…', totalPages - 4, totalPages - 3, totalPages - 2, totalPages - 1, totalPages];
  return [1, '…', cur - 1, cur, cur + 1, '…', totalPages];
}

function renderPager() {
  const totalPages = pagerTotalPages(pagerState.total, pagerState.size);
  pagerState.page = Math.min(totalPages, Math.max(1, pagerState.page));
  const cur = pagerState.page;

  document.getElementById('pagerNumbers').innerHTML = pagerItems(totalPages, cur)
    .map((item) => (item === '…'
      ? '<span class="page-ellipsis" aria-hidden="true">…</span>'
      : `<button class="page-button${item === cur ? ' active' : ''}" type="button" data-page="${item}"${item === cur ? ' aria-current="page"' : ''}>${item}</button>`))
    .join('');

  document.getElementById('prevPage').disabled = cur <= 1;
  document.getElementById('nextPage').disabled = cur >= totalPages;
}

function gotoPage(page) {
  const totalPages = pagerTotalPages(pagerState.total, pagerState.size);
  const target = Math.min(totalPages, Math.max(1, Math.round(page)));
  if (target === pagerState.page) return;
  pagerState.page = target;
  pagerState.render();
}

function submitJump() {
  const input = document.getElementById('jumpPage');
  const raw = (input.value || '').trim();
  input.value = '';
  if (!raw) return;
  const value = Number(raw);
  if (!Number.isFinite(value)) return;
  gotoPage(value);
}

function bindPager(renderList) {
  pagerState.render = typeof renderList === 'function' ? renderList : () => {};
  document.getElementById('prevPage').addEventListener('click', () => gotoPage(pagerState.page - 1));
  document.getElementById('nextPage').addEventListener('click', () => gotoPage(pagerState.page + 1));
  document.getElementById('pagerNumbers').addEventListener('click', (event) => {
    const target = event.target.closest('[data-page]');
    if (target) gotoPage(Number(target.dataset.page));
  });
  document.getElementById('pageSize').addEventListener('change', (event) => {
    pagerState.size = Number(event.target.value);
    pagerState.page = 1;
    pagerState.render();
  });
  document.getElementById('jumpPage').addEventListener('keydown', (event) => {
    if (event.key === 'Enter') { event.preventDefault(); submitJump(); }
  });
  document.getElementById('jumpPage').addEventListener('blur', submitJump);
}
```

`renderList` 由项目实现，负责按 `pagerState.page` / `pagerState.size` 截取数据、渲染表格并在末尾调用 `renderPager()`。它通过 `bindPager(renderList)` 注册到 `pagerState.render`，标准脚本内部只调用 `pagerState.render()`，不直接引用项目渲染函数，避免两处作用域不一致。

### 7.4 集成点

1. 列表渲染入口按 `pagerState.size` 和 `pagerState.page` 截取当前页数据，末尾调用 `renderPager()`。
2. 拿到新数据后先更新 `pagerState.total`，再进入渲染入口；页码钳制在 `renderPager()` 内完成。
3. 筛选、搜索、切换视图时把 `pagerState.page` 重置为 1，再走渲染入口。
4. 初始化时先调用一次 `bindPager(renderList)`，再按默认 `size: 10`、`page: 1` 渲染一次。顺序不能反：`bindPager` 之前 `pagerState.render` 是空函数，此时翻页只会改页码、不刷新列表。静态稿把页码直接写成 `1` 与禁用态即可，不引入脚本。
5. 本参考按单页单个分页条实现；同一页面需要多个分页列表时，各自封装实例并各自维护 DOM id，不复用同一组节点。

## 8. 验收清单

- 页码序列符合第 4 节四种分支；总页数 `8`、当前页 `1` 时渲染为 `1 2 3 4 5 … 8`。
- 首末页时上一页或下一页禁用，且禁用态同时有透明度和 `disabled` 属性。
- 当前页有 `aria-current="page"`，不只靠颜色区分。
- 跳页输入 `Enter` 与失焦都能生效，非数字与空值清空输入且不翻页。
- 跳页越界钳到最近边界，跳转后输入清空。
- 切换每页条数后回到第 1 页；筛选后回到第 1 页；数据缩减后不出现空页。
- 分页条内没有「共 N 条」「第 X / Y 页」等重复总量文案。
- 「跳至 … 页」保持单行，未被下拉挤压成竖排；页码按钮最小宽度一致，位数增加时按内容伸展，不压缩文字。
- 窄视口（≤ `640px`）下分页条换行，右侧「跳至 … 页」整组落在同一行，不被拆散、不被右边界裁切。

# 个人深灰科技风格

适用范围：已明确选择 personal 档案的原型。它是可移植的个人视觉基线，不含品牌、项目菜单或业务规则。项目已有设计系统时不能自动覆盖。

## 事实源与使用

视觉值的唯一维护源是 `assets/个人风格Token.json`；[个人风格原型模板](个人风格原型模板.html)内联同一组 Token，可离线打开，[默认预览](个人风格原型模板_默认预览.png)用于产品界面视觉核对，[组件状态预览](个人风格组件状态预览.png)用于组件状态核对。改 Token 时须同步模板与两份预览，不能只改一份。

依据用户选定的机器人软件工作台预览，采用石墨灰层次、荧光绿重点、紧凑导航和模块化卡片。颜色、字体、尺寸与阴影是模板归纳实现值，非 Figma 节点实测值；尚未读取的原组件、变量及动效不作为原稿事实。此前暖白方案由本档案替换。

白色主文、浅灰辅助文；使用离线系统字体。局部立体装饰使用柔和渐变与接触阴影，不使用全屏辉光、霓虹描边或毛玻璃覆盖正文；外部原图、品牌与模型不随 Skill 分发。

## 壳层与空间

- 完整桌面评审页使用 `1440×900`，窄侧栏 `88px`；导航图标保留短标签和可访问名称。工作区在右侧，无已确认需求时不增加顶层平台导航、全局页签或折叠操作。
- 模板内的菜单、表格和示例对象仅演示布局，复制时按确认的信息架构整体替换，不将示例功能视为需求。
- 内容内边距 `24px`，区块间距 `24px`，控件内间距 `8px`。石墨灰工作区、较深侧栏、逐级提亮的面板；面板 `16px` 圆角、细边和柔和阴影。其余间距使用 Token 档位。
- 标题 `26/34px`，正文 `14/22px`，辅助 `12/18px`；字体使用 Token 的系统字体栈。同一区域密度一致，不靠缩字或浅化正文解决拥挤。卡片按任务分组，不强制列表、对话或设置页面仪表盘化。

## 控件与状态

本节只锁定控件默认态的视觉基线；组件登记、状态矩阵与静态/交互边界见[个人风格 UI 与交互规范](个人风格UI与交互规范.md)，两处不重复定义。

- 按钮高 `36px`；输入/选择高 `40px`；圆角 `10px`。主操作荧光绿底、深色文字；次操作深灰，危险操作浅红；输入控件采用下沉深灰底与可见边线。所有状态保留可判断文字，绿色不铺满全部卡片；蓝紫色只作辅助类别或装饰。
- 开关 `36×20px`，圆点 `16px`；只表达已定义的即时二元切换。Checkbox/Radio 为 `16px`。
- 页签以文字和底线区分当前态；表格用下沉深灰表头、细边分隔；行操作保持明确文本。筛选标签在上、控件在下；查询在前、重置在后。
- 弹窗、抽屉与 Toast 继承同一 Token；模板目前只有确认弹窗样例，抽屉与 Toast 不自行新画。静态评审只画组件本体；组件参考面板为独立示例，不是页面中的额外产品功能。
- 图标继续使用 Skill 登记的 Lucide 资产、currentColor 和统一线宽，不以 emoji 或字符替代，不因选择个人风格改换图库。

## 复制与交付

模板提供一个原创 CSS 几何立体装饰，仅供欢迎与空状态复用，不是图标、业务对象或原稿模型，不替代 Lucide 资产；业务表格和输入区域不放漂浮装饰。新增角色和素材需先明确来源与状态再登记。

静态模板无自动播放、无业务脚本。交互版可用 `140ms ease-out` 的颜色和边线过渡表达 hover、focus、press，并支持减少动态效果；不得以装饰动效表达真实进度。

复制模板而非重写近似外观；替换业务内容槽、当前导航与状态，保留锁定的 Token 和壳层。删去不需要的组件示例、样例字段与数据；不得为凑齐模板增加需求。

静态与交互原型采用同一 DOM 与视觉 Token，区别只在授权范围内的行为深度。模板当前只演示静态默认态，不能将未实现点击当成业务可用。按[档案格式](原型风格档案.md)记录来源，再完成严格审计、浏览器与视觉验证。

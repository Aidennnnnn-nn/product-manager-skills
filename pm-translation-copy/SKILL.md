# 项目翻译词条与产品文案规范

本 Skill 使用 `references/翻译平台词条数据_2026-11-16.csv.gz` 作为当前翻译平台导出快照，包含 `dict_key`、分组、适用平台、中文、英文和多语言文案。它是 AI MATRIX 项目中 PRD 用户可见文案的词条事实源。

## 适用范围

适用于 PRD、原型说明、按钮名称、菜单项、字段标签、占位文案、校验提示、错误提示、状态反馈、批量处理结果、邮件和通知文案。技术字段、API 参数、内部评审说明和不展示给用户的追踪信息不强制使用本 Skill。

## 强制规则

1. 先确认目标平台和语言。平台未知时写“待确认”，不得把一个平台的词条直接当成所有平台的通用文案。
2. 先按 `dict_key + 目标平台 + 目标语言` 精确查找，再按同一平台和分组查找相同语义文案。
3. 找到精确 key 时，沿用该 key 的对应语言版本和占位符；不得为了语气自行改写已有文案。
4. 同一中文或英文可能对应多个 key。文本相同只能作为候选，必须结合分组、平台、场景和占位符判断；无法唯一判断时列出候选并标记“待确认”。
5. 没有精确 key 时，可以使用同一平台、同一分组且语义和占位符一致的相近词条，并在 PRD 中记录“复用来源 key”和匹配理由。
6. 不同平台之间只能把明确的通用词条作为候选复用；平台范围不同、语气不同或业务结果不同的词条不得静默跨平台复用。
7. 目标语言缺失时，不用模型记忆补译。保留已存在的中文基准文案，标记缺失语言并生成待新增翻译事项。
8. 没有精确或安全相近词条时，输出“待新增翻译需求”，至少包含建议 key、分组、平台、中文基准、英文基准、目标语言、使用场景、占位符和需要确认的文案。
9. 所有变量、占位符、转义符和换行语义必须保持一致。文案替换前检查中文、英文和目标语言的占位符集合；不一致时标记待确认，不自行修正。
10. PRD 中的用户可见文案应同时记录 `dict_key` 或“待新增翻译”，并写清平台和语言范围，便于原型和研发回溯。

## 查找流程

优先使用附带脚本执行检索，避免只凭记忆或文本相似度选词条：

```bash
python3 scripts/查询翻译词条.py \
  --key account_created \
  --platform semsplus \
  --lang zh-CN
```

按用户可见中文或英文查找：

```bash
python3 scripts/查询翻译词条.py \
  --text "账户已成功创建" \
  --platform semsplus \
  --lang zh-CN \
  --limit 10
```

脚本返回 `exact_key`、`exact_text`、`ambiguous`、`similar_candidates`、`language_missing` 或 `not_found` 等结果。`ambiguous` 和 `similar_candidates` 只提供候选，不得自动写入为已确认文案。

## PRD 输出格式

涉及界面或用户通知时，文案按以下信息落地：

| 文案位置 | 中文文案 | 目标语言文案 | dict_key | 平台 | 状态 |
| --- | --- | --- | --- | --- | --- |
| 按钮/字段/提示/结果 | 词条文本 | 对应语言文本 | 精确 key 或待新增 | 目标平台 | 已复用 / 待确认 / 待新增翻译 |

如果同一文案在多个入口使用，保持同一个 key、同一个平台范围和同一个语言版本；入口差异必须有词条或 PRD 依据。

## 待新增翻译需求模板

找不到安全匹配时，使用以下结构，不把临时文案伪装成既有翻译：

```text
待新增翻译需求
- 建议 key：<稳定、可读、未占用的候选 key>
- 分组：<basictranslation / alarmname / alarmreason / alarmsolution / report / email / partspurchase / feedback / 待确认>
- 适用平台：<平台列表>
- 中文基准：<用户确认后的中文文案>
- 英文基准：<如需英文；未确认则写待确认>
- 目标语言：<缺失语言代码>
- 使用场景：<页面、按钮、字段、状态或通知位置>
- 占位符：<逐字列出；无则写无>
- 未决原因：<没有精确 key、平台不匹配、语言缺失或语义无法唯一判断>
```

## 数据边界与更新

- 当前快照日期为 `2026-11-16`。数据源更新时，以新的翻译平台导出文件生成新日期快照，不覆盖旧快照。
- 不删除重复语义的不同 key；重复文本可能服务于不同平台、分组或历史业务。
- 当前数据有 47,052 条唯一 key、25 个语言代码、9 个适用平台和 9 个分组（含空分组）。详细统计见 [翻译词条目录说明](references/翻译词条目录说明_2026-11-16.md)。
- 当前快照来自用户提供的本地导出文件，不代表翻译平台实时状态；写 PRD 时以当前 Skill 快照为准，发现平台已变更时列为待同步事项。
